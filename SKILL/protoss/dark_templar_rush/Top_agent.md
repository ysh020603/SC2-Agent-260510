# Summary

Build a compact Gateway opening with Pylon, Assimilator, CyberneticsCore, and enough early Zealot/Stalker production to survive. Progress through TwilightCouncil to DarkShrine, keep the route concealed where possible, and produce the first DarkTemplars as soon as resources and supply allow. Use them for worker and tech damage while expanding behind the pressure; add WarpGateResearch, BlinkTech, conventional Gateway units, and detection-resistant follow-up if the opponent is already prepared.
