# V2 Upgrade Policy

An upgrade is useful only when its beneficiaries, timing, and opportunity cost fit the live match.

- Identify the dominant current and queued combat units.
- Verify that the upgrade affects those units and preserve exact relation direction.
- Verify researcher, prerequisites, previous level, cost, and converted time.
- Prefer an upgrade when substantial army value will benefit for long enough to repay the cost.
- Prefer units and production during immediate survival, severe supply risk, or a large army deficit.
- Never queue upgrades for an abandoned composition or skip required earlier levels.
